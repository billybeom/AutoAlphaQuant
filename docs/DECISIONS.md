앱 청사진 v1.2~v1.9에서 한 건씩 확정됐고, v1.9 시점에 **9건 전부 확정 = 설계 확정본**이 됐습니다.

| # | 결정 | 코드에 어떻게 나타나 있나 |
|---|---|---|
| **1** | **호스트 = Android 폰 1대 + 서버 워치독** | `apps/app_operator_android`가 유일한 실행 주체. 워치독(healthchecks.io류)이 하트비트를 **밖에서** 감시 — 죽은 엔진은 「나 죽었다」를 보내지 않으므로 |
| **2** | **엔진 언어 = Dart 재구현** (Python 이식) | `core_engine`이 순수 Dart. 웹 미리보기도 같은 계산부를 로컬 재계산. 🔴 **등가성 게이트**: 골든벡터 196 서브케이스 전량 통과 전에는 DRY_RUN을 벗어나지 않습니다 |
| **3** | **1차 자동화는 국내상장 ETF만** | 미국 직접 주문 0건. 계좌 연결 화면에 「해외주식」이 없습니다. (v2.31 P0S에서 미국 심야 2단계가 소멸) |
| **4** | **엔진 명세(00_SPEC) 개정 4건** | Flutter 앱 = 명세 밖 별도 소비 시스템(읽기 전용 + 통제 명령 API) · 스케줄링은 cron이 아니라 거래소 캘린더 기반 정확 알람 + Foreground Service · 자격증명은 OS 키체인으로만(NR-5) → SPEC v2.26 |
| **5** | (결정 2에 흡수) 웹 미리보기 위치 | 순수 계산부가 전 플랫폼에 컴파일되므로 「로컬 재계산」으로 해소 |
| **6** | **웹·데스크탑은 읽기 전용 + 킬스위치 「발동만」** | 뷰어에서 **해제는 불가**. 해제는 폰에서만, 48h 대기 + 체크리스트 7항 순차. 브로커·주문·키 코드는 웹 타깃 빌드에서 **제외**(코드 리뷰로 대체하지 않음) |
| **7** | **스키마 4건 승인 · D2 = 원화 현금 대기 · 알림 P0/P1/P2 엔진 승격** | 알림 등급은 **조치 기준**이며 엔진에서 한 번만 정의합니다. 🔴 표시 계층의 사적 재분류 금지 → SPEC v2.28 |
| **8** | **수익률 노출 절충안** | 월간 리포트가 기본, 상세 손익은 마찰 뒤 탐색, 손익은 접힘. 🔴 **홈·알림·위젯·FGS에 손익 숫자를 두지 않습니다** — 홈의 숫자는 슬리브별 목표 대비 편차·밴드 여유·과정 지표 3개 |
| **9** | **5탭 셸 · 저널 범위 · 워치독 · Supabase 명령 테이블(INSERT-only) · QR 페어링** | 뷰어의 쓰기는 append-only 명령·이벤트 테이블 4종 + RLS로 **서버에서 한 번 더** 막습니다. 앱 단독 방어에 기대지 않습니다 |
