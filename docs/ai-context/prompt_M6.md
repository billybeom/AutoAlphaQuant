■ M6 전용 규칙
- **«현재»는 전일 종가 기준입니다**(엔진은 일 1회 배치). 보유·평가 화면에 «현재»를 쓸 때는 기준일 고지를 반드시
  함께 렌더하되, 문구는 **`AsOf.label`을 그대로** 찍습니다(별도 «AsOfStamp» 타입은 없습니다). 오래된 데이터 배너
  문구는 `AsOf.staleLabel`이고, 명세 §2-1의 as-of 갈래를 문구 분기로 하드코딩하지 마십시오(열거값 미확정).
- **목록은 `ListResult<T>` 봉투로 옵니다** — 빈 목록에도 `asOf`·`emptyKind`·`emptyLabel`·`hasMore`가 실려 옵니다.
  빈 상태 문구를 쓰지 말고 `emptyLabel`을 그대로 찍고, 무한 스크롤은 `limit += 100` 재구독 하나뿐입니다(커서 없음).
- **차단 표기는 명세 §2-2 표에 있는 것만** 씁니다. 새 배지·색·배너 문구도, 배너 동시 발생 우선순위도 화면이 정하지 않습니다.
- **종목 손익은 기본 접힘**이고 `watchHoldings()` 기본 구독은 `includePnl: false`입니다. J-4는 «채점 전»에
  손익·결과가 보이면 blind가 아닙니다.
- 슬리브는 **A / B / C 3칸**입니다(v2.31 P0S). SAT 칸·TIER 위젯·손절선 카드는 `satellite_enabled=false`에서
  **숨깁니다**(비활성 아님).
- POT 서브북 행은 슬리브 A의 **하위 행**입니다(회계 소속 A). 4번째 슬리브가 아니고, 목표 A 20 / B 42 / C 잔여와
  비교되는 값은 회계 기준(A는 POT 포함, C는 POT 제외)입니다. `basis`·상위 슬리브 필드가 오면 그대로 따르고,
  필드가 아직 없으면(⚠️ `SleeveAllocationRow` 미정의) 픽스처 고정 모드로만 만들고 요청 목록에 올리십시오.
- 슬리브 B 행의 «계좌 잔고»와 «투자분»은 다른 값입니다. 신호가 꺼져 슬리브 C에 파킹된 몫은 «미달»이 아니라
  규칙의 정상 동작이니 편차 강조·경고색·달성률 게이지로 그리지 마십시오. SMA 3-트랜치는 초기 편입 절차가
  아니라 **상시 투자비율 규칙**(0 / ⅓ / ⅔ / 1)이므로 «잔여 단계»·«초기 n/6» 같은 끝이 있는 라벨을 만들지 마십시오.
- 🆕 X7 안내 화면 5개가 이 모듈에 붙습니다 — A-1 오늘의 매매 안내(인박스) / A-2 안내 상세 / A-3 수기 체결 기록 /
  A-4 미이행 사유 1탭 분류 / L-3 원장 실사. **A-3·A-4·L-3은 폰 전용**이고(뷰어에서는 «비활성»이 아니라 부재),
  A-1·A-2는 조회 전 플랫폼이되 뷰어에서는 종목·수량·지정가가 오지 않습니다. **안내 목록과 매매일지를 한
  목록으로 합치지 마십시오** — 안내는 계획, 일지는 사실입니다.
- A-2에 안내 수량·지정가를 편집하는 컨트롤을 만들지 마십시오(안내를 고치면 그것은 더 이상 규칙의 출력이
  아닙니다). A-3은 입력란을 **비운 채** 열고 참조 카드만 위에 둡니다 — 허용되는 프리필은 「안내 수량 채우기」
  버튼 하나뿐이고 가격·거래일에는 그 버튼도 없습니다. 부분 체결용 별도 버튼을 만들지 말고(실제 체결 수량을
  적으면 그것이 부분 체결입니다), 제출 후 **낙관 갱신 금지** — 「기록 버튼을 눌렀다」와 「원장에 들어갔다」는
  다른 사건이고 그 구별이 표류 인지의 출발점입니다.
- L-3은 원장 현재값을 **미리 채워 보여 주지 않습니다**(앵커링 방지 — 그대로 확인만 누르면 실사가 아닙니다).
  A-4의 「이행하지 않았습니다」는 「기록하기」와 **동등한 크기·위치**입니다(아무것도 안 하기 동급).
- A-1에서 **«안내 0건»과 «오늘은 아무것도 하지 마십시오»는 다른 상태**입니다. 전자는 목록 봉투의 `emptyLabel`을
  찍고, 후자는 엔진이 보낸 **안내 1건**(발행이 억제된 날에만 옵니다)을 카드로 그립니다. 목록이 비었다고 그
  문장을 화면이 만들면 규칙이 조용히 멈춘 날과 아무 일 없는 날을 사람이 구별할 수 없게 됩니다.
- L-1 대조 보드의 **칸 수를 하드코딩하지 마십시오** — 배열로 받아 그대로 그립니다(자가보고 쌍이 늘어 5칸입니다).
  칸에 «점검하지 않음» 상태가 따로 있습니다(해당 없음 플래그). 그것을 «일치»·«통과»로 그리면 안 본 것이 본 것이
  되므로, 상태 값을 색·문구로 임의 매핑하지 말고 뷰모델 필드를 그대로 쓰십시오.
- 수기 체결의 **정정·무효는 M5-12(안전 화면) 소유**라 딥링크만 겁니다. L-2는 X5 정정 이력 **읽기** 화면이며
  수기 체결 정정 진입을 만들지 않습니다(정정 체인은 J-2가 계단식으로 그립니다).
- J-3은 **폰 전용**입니다. 웹·iOS 빌드에 그 폼이 포함되면 안 되고, 뷰어에서 쓰기 버튼은 «비활성»이 아니라 **부재**
  여야 합니다. L-1·L-2는 **읽기까지만**이고 정정 마법사(M5)에는 딥링크만 겁니다.
- 명세 §2-7의 ⚠️ M2 미정의 타입 7건(J-2 결정 스냅샷·J-3 폼 스펙·J-4 리뷰 카드·J-5 단계·H-1/H-3 슬리브 배분 행·
  H-2 손절선 정규값·L-2 정정 이력 행)은 이름을 지어내지 말고 요청 목록으로 제출하고, 그 전까지 해당 화면은
  픽스처 고정 모드로만 만듭니다.
