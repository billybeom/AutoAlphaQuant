## 누구에게 무엇을 주나

**5부 규칙**(07 §2-2): 한 AI가 받는 문서는 **정확히 5부**입니다 — ① 해당 화면 명세 ② `01` ③ `00` 발췌
④ `domain_contracts` 패키지 실물 ⑤ `08` Mermaid. 프롬프트는 문서가 아니라 **지시문**이라 5부에 세지 않습니다.

## 갱신 규칙

🔴 **`01`·`02`~`05`가 바뀌면 이 폴더를 다시 조립합니다** — Claude C4 6단계. 사본을 손으로 고치지
않습니다. 손으로 고치는 순간 정본이 둘이 되고, 다음 AI는 어느 쪽을 읽었는지 말해 주지 않습니다.

절차: ① 정본 변경 확인 → ② 이 폴더 재조립(프롬프트 4종 포함 — 07 본문이 바뀌었을 수 있음)
→ ③ `rounds.md`에 새 «팩 판» 행 추가 → ④ 옛 판으로 작업 중인 라운드에 **재발송**(반려가 아님)
→ ⑤ `inbox/`의 미답 질문 중 이번 갱신으로 해소된 것 상태 변경 → ⑥ `melos run test:contracts` 통과 확인.

- 프롬프트 본문(07 §3 공통 머리 · §4~§7 블록)은 **한 글자도 고치지 않습니다.** 고칠 곳은 07 정본이고,
  이 폴더는 그것을 치환값만 채워 다시 뽑습니다.
- `fixtures_README.md`의 파일 목록은 픽스처가 추가·삭제될 때마다 다시 뽑습니다.
- `contracts_bundle.md`는 `domain_contracts/lib/`가 바뀔 때마다 다시 뽑습니다.
