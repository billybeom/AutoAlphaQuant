# `rounds.md` — 라운드 로그

한 «라운드» = **한 AI에게 한 번 준 것과 받은 것**. 이 표가 「누가 무엇을 언제 받았고 지금 어디까지
왔는가」의 유일한 색인입니다. 팩을 다시 조립했으면(01·02~05 변경) **행을 새로 추가**하고,
이미 보낸 행의 값을 덮어쓰지 않습니다.
