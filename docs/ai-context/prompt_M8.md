  결과도 M2가 준 그룹 그대로 그립니다. **정상 = 무소식** — 아무 일 없을 때 초록 배지를 늘어놓지 마십시오. 조치가

  그 항목이 있을 때만 버튼을 그려 명령 1회를 부릅니다. 🔴 «읽음 처리»를 화면 로컬 상태로 만들지 마십시오 —
  사다리를 멈추는 것은 엔진이고, 화면만 조용해지면 사람은 멈췄다고 믿는데 알림은 계속 옵니다.
