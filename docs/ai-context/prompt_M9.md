■ M9 전용 규칙 — 시크릿을 다루는 모듈이라 규칙이 가장 셉니다
- **설정 등급(GENERAL·OPERATIONAL·RULE)을 화면이 정하지 않습니다** — 뷰모델의 `tier` 필드를 그대로 씁니다. 생체
  실패·미등록이면 해당 등급을 **읽기 전용으로 축소**하고 `BIOMETRIC_UNAVAILABLE` 문구를 띄웁니다. **비밀번호 대체
  경로를 임의로 만들지 마십시오** — 마찰을 우회하는 뒷문이 됩니다.
- **시크릿 입력 위젯을 새로 만들지 마십시오.** 온보딩(X3)과 M9 키 관리는 **같은 `SecretField`**를 씁니다. 두 벌이
  생기는 순간 한쪽만 고쳐지는 사고가 시작됩니다. 자체 붙여넣기 버튼·전체 표시 토글·임시 저장·«한 번 더 입력»
  필드·자체 정규식 검사를 추가하지 마십시오. 시크릿·계좌 전체번호는 **재표시·복사·로그 금지**, 해당 라우트에
  `FLAG_SECURE`를 켜고 **나갈 때 끕니다**. 마스킹 해제는 생체 재인증 경유이고 그 판정도 Claude 소유입니다.
- **손익 금지**: M9 어디에도 평가손익·수익률·평가액이 없습니다. 유일한 예외는 S04 배분 편집기의 **백테스트 근거
  카드(CAGR/MDD)** — 실현 손익이 아니라 규칙의 이력 통계이고, 그마저 뷰모델 문자열입니다.
- S04 배분 편집기: **자동 정규화 금지**(합이 100이 아니면 그 사실을 표시만 하고 대신 고치지 않습니다), 금 상한·
  슬리브 상하한은 **엔진 config 키에서 읽어 표시**하고 하드코딩하지 않습니다. 새틀라이트 슬라이더는
  `satellite_enabled=false`일 때 **숨깁니다**(비활성 아님).
- «적용»·«실전 전환»·«복원»·«키 회전»은 **`SettingsActions.run(...)` 1회 + 결과의 `handoffRoute` 이동**으로
  끝납니다(01 §4-3 — 이것은 뷰어 쓰기 `CommandApi` 5종이 **아닙니다**). 냉각 30일·12월
  창·2단계 승인·킬스위치 해제 48h 대기·체크리스트 7항은 M5 소유이며, 그 UI를 자체 구현하거나 «요약 확인
  대화상자»로 대체하면 반려입니다. **이 마찰은 버그가 아니라 사양입니다.**
- 뷰어(웹·데스크탑·iOS) 빌드에 폰 전용 라우트가 포함되면 안 됩니다(비활성 아니라 **부재**). 뷰어 조회 화면에는
  «폰에서만 변경할 수 있습니다» 배지가 붙고, 앱 잠금 오버레이가 **킬스위치 진입 경로를 덮지 않게** 하십시오.
- S10 진단의 골든벡터 총계는 **상수로 적지 마십시오**(미확정) — 값이 없으면 칸을 비우고 질문 목록에 적습니다.
  S08은 채택 자체가 미결인 조건부 화면입니다. 슬리브 칸 수·잡 목록·램프 라벨은 **배열/필드에서** 그립니다.
- **기각 등록부 항목을 편집 대상으로 만들지 마십시오.** 실측 끝에 기각된 후보(대표: 원화 강세 오버레이 —
  엔진 `Config.fx_overlay` 기본 None, 같은 계열 재개 금지)를 배분 편집기의 프리셋·실험 토글·«고급» 섹션

  링크·자리표시자도 만들지 마십시오**(빈 링크가 됩니다). 목록·사유 문구는 전부 뷰모델이 줍니다.
- **월 납입 운영값은 M9 설정 항목**입니다(2026-09-07 발주자 결정 — 기본 100,000원, 언제든 변경 가능).
  금액·문구는 **엔진 config에서 읽어 표시**하고 하드코딩하지 마십시오. 저장은 다른 설정과 똑같이
  `SettingsActions.run(...)` 1회 + `handoffRoute`로 끝나고(화면이 직접 저장하지 않습니다), 정정은 새 행이라
