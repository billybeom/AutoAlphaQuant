# `inbox/` — 질문·요청 접수함

AI가 만든 **질문 목록**과 **추측한 것 목록**이 여기로 들어옵니다. 채팅으로 오간 답은 다음 AI에게
전달되지 않습니다(07 §2-3). 답은 **문서·픽스처 갱신으로만** 돌아가고, 그 경로가 이 폴더입니다.

## 파일 이름 규약

```
<카드ID>_questions.md
```

- `<카드ID>` = 그 라운드에 맡긴 화면 ID를 **대문자·하이픈 없이** 그대로. 예 `J-1` → `J1`,
  `S7-1` → `S7-1`은 하이픈을 유지(화면 ID 자체가 하이픈을 포함하므로 **ID 원문 그대로**가 원칙).
- 실제 예: `J1_questions.md` · `S7-1_questions.md` · `S-01_questions.md` · `S01_questions.md`
- 한 카드에 여러 라운드가 붙으면 같은 파일에 **추가**합니다(새 파일을 만들지 않습니다).
- 답이 달린 항목은 지우지 말고 상태만 바꿉니다 — 같은 질문이 다음 라운드에 다시 오는 것을 막습니다.

## 형식 — 표 하나

| 번호 | 카드ID | 종류 | 질문·추측 | 막힌 곳 | 제안 | 상태 | 답 |
|---|---|---|---|---|---|---|---|
| Q1 | J-1 | 질문 | `SleeveAllocationRow`에 `basis` 필드가 있습니까 | H-3 목표 대비 편차 | 픽스처 고정 모드로 진행 | ⬜ 미답 | |
| A1 | J-1 | 추측 | 빈 목록에서 `emptyLabel`이 없을 때 자리를 그리지 않음 | J-1 타임라인 | — | ⬜ 미답 | |

- **종류** = `질문`(모르는 것) / `추측`(문서에 없어 임의로 정한 것) 둘뿐입니다. 번호는 `Q*`·`A*`로 갈라 붙입니다.
- 🔴 틀린 접두로 이미 붙은 번호는 **고치지 않습니다**(코드 주석·PR 본문이 번호로 참조합니다) — **종류 칸이 정본**이고,
  파일 머리말에 «Qn~Qm 은 추측» 한 줄과 다음 번호를 남깁니다(2026-09-24 · R2-Bob-J2J3).
- **상태** = `⬜ 미답` · `🟡 확인 중` · `✅ 답함(문서 갱신)` · `🔴 반려(그 구현은 폐기)` 넷.
- **답** 칸에는 결론이 아니라 **어느 문서 어느 절이 갱신됐는지**를 적습니다 — 결론만 적으면 다음 AI가
  그 문서를 읽지 않고 이 표를 읽습니다.
- 🔴 답을 이 표에만 적고 정본(01·02~05)을 고치지 않으면 **정본이 둘이 됩니다.** 표는 색인이지 정본이 아닙니다.

## 넣지 않는 것

- 실계좌번호·앱키·토큰·비밀번호·실보유량 — 질문 본문에도 넣지 않습니다.
- 엔진 명세(`06_시스템설계`)·청사진 HTML 발췌 — 여기에 붙여넣는 것도 배포입니다(07 §2-3).
