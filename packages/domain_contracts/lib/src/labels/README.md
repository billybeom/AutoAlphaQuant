# `lib/src/labels/` — 코드→문구 매핑 (G3 예정)

정본: 01_M2_도메인계약 **§3**

`exit_kind` 6종 · SAF 코드 접두(37종) · `verdict_code`(X2 재판정) · 원인 코드(X5 대사) · 차단 플래그 `flag_id`.

## 🔴 이 폴더의 성격을 오해하지 말 것

**문구는 엔진(M2) 소유이고 런타임에 DTO의 `label`·`actionLine`·`clearInstruction`·`headline`·`stateLabel` 필드에 실려 온다.** 여기 두는 것은 «어떤 **코드**가 오는가»의 목록·상수이지, 화면이 코드를 보고 문자열을 고르라는 사전이 아니다.

- 화면이 코드→문구 매핑을 만들면 §7 **C-5**가 빌드를 실패시킨다.
- 화면의 정적 UI 라벨(「닫기」·「기간」)은 여기가 아니라 **각 `ui_*` 패키지의 `lib/l10n/labels.dart` 한 파일**에 있다(§1-5).
- 판단 기준: 데이터가 바뀌어도 글자가 같으면 정적 라벨, **데이터·상태에 따라 달라지면 사유 문구**다. `if 상태 then A else B`처럼 **분기로 고르는 것은 정적 라벨이 아니라 생성**이다.

## ⚠️ 미결 (임의 확정 금지)

- `CORPORATE_ACTION`(X2) vs `CORP_ACTION`(X5) **원인 코드 중복** — 상세 설계에서 하나로 통합한다(01 §8-6).
- `AsOf.staleReasonCode` · `FillVisibility` 열거값 — 초안값만 있다(01 §8-8).
