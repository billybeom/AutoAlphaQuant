## 🔴 여기 골든이 지켜야 할 것

`safety_states.json`(normal·alert·reduced·halted·stopped) 다섯 상태와 해제 게이트 진행 프레임을 모두 찍는다. 골든이 확인하는 것은 «예쁜가»가 아니라 다음이다.

1. **해제 게이트의 단계가 실제로 순차인가** — 건너뛸 수 있는 컨트롤이 프레임에 없는가.
2. **킬스위치 발동에 확인 대화가 붙지 않았는가**(즉시 발동이 사양이다).
3. **카운트다운·잔여 시간이 엔진 문자열 그대로인가** — 화면이 계산한 숫자가 아닌가.
4. **`clearInstruction`이 플래그마다 다르게 나오는가** — 한 문구로 뭉뜽그려지지 않았는가.
