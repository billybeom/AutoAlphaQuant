# `lib/src/risk/` — 청산 티어·손절선·한도 게이트 (일부 — E1·E3a)

> 들어온 것: `position_sizing.dart`(이중 상한 사이징 · GV-8 — v2.31 에서 집행 대상은 아니지만 Decimal 규약의 게이트). `breaker.dart`(드로다운 서킷브레이커 · 재개 자격 · 슬리브별 승수 — E3a). 한도 판정은 E3b.

정본: `06_시스템설계/03_알고리즘.md §4` · `04_안전장치.md`

담을 것: 청산 티어 판정(TIER 0·1A·1B·1.5·2·3) · 손절선(절대·트레일링·HWM) · SAF 한도 게이트 37종 · 드로다운 서킷브레이커(`normal`→`alert`→`reduced`→`halted`→`stopped`).

- 🔴 **`exit_kind` 6종과 SAF 코드는 사유 문구의 원천**이다(01 §3). 코드와 함께 **엔진이 만든 문장**을 결정에 실어 보낸다 — 화면이 코드로 문장을 고르는 일이 없어야 한다.
- 🔴 **경보 피로 방지**: 조치가 다르면 다르게 말한다. 플래그마다 `clearInstruction`이 다르고, 고칠 수 없는 조건으로 점검을 실패시키지 않는다.
- 🔴 `RECON_MISMATCH`는 **다음 배치 재대사에도 남는 것만** 주문 차단으로 승격한다.
- 🔵 v2.31 P0S에서는 티어 대부분이 비집행이다(개별주 소멸). 판정 코드는 유지한다.
