## 무엇을 하나

골든벡터는 **동결된 입력 → 기대 출력 정답지**다. 언어 중립 자산이라 파이썬 파일럿에서 쓰던 JSON을 **그대로** Dart 재구현의 등가성 게이트로 쓴다. 여기 테스트는 그 JSON을 읽어 `core_engine`의 출력과 비교한다.

## 🔴 규칙

1. **골든 JSON을 이 저장소에서 다시 만들지 않는다.** 원본을 복사해 오고, 값을 손대야 할 이유가 생기면 그것은 전략 변경이므로 `06_시스템설계`에서 결정한다.
2. **전량 통과 전에는 DRY_RUN을 벗어나지 않는다**(결정 2). 이 폴더가 그 게이트다.
3. **테스트가 깨졌을 때 기대값을 고치지 않는다.** 깨진 것은 계산이 바뀌었다는 신호다. GV-8a는 **1 ULP 차이로 `binding` 판정이 뒤집힌 실측 사례**이며, C-9가 그 벡터(GV-8a·8d·8f)를 Dart로 재현한다.
4. ⚠️ **서브케이스 총계를 상수로 적지 않는다.** 196 → … → 345(v1.15)로 재합산된 이력이 있고 v1.16·v1.18~20 신설분 반영 여부가 미확인이다(01 §8-14). 화면·계약 어디에도 총계를 굳히지 않는다.
